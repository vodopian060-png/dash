# Неруд-Логистик на ладони

Страница бизнеса: рейсы, перевозчики, машины, заказчики, долги, деньги. Открывается по паролю; все данные в `data/*.enc` зашифрованы (AES-GCM, ключ из пароля). Новые таблицы загружаются прямо со страницы (вкладка «Загрузка») и записываются в репозиторий через GitHub API с личным токеном.

- `index.html` — страница (парсер xlsx, расчёты, интерфейс)
- `data/meta.enc` — список загруженных файлов
- `data/grafik.enc`, `data/sverki.enc`, `data/bank-XXXX.enc` — данные
